# RETUNE v0.4 iOS Design Spec

## 1. Purpose

RETUNE v0.4 is an iOS-native vocal pitch training app whose goal is not merely to show whether a sung note is sharp or flat. It trains the chain required for accurate singing:

> hear a reference → internally generate the target → reproduce it with the voice → transfer the skill into short melodies and real singing conditions

The app must diagnose where this chain fails and automatically prescribe short exercises for the weakest skill.

This document supersedes the older PWA-oriented v0.1 design for new implementation work. The prior PWA documents remain in the repository as historical design records only.

## 2. Platform and Distribution

- Native iOS app
- Swift / SwiftUI
- Audio capture and playback with AVAudioEngine / AVAudioSession
- Local-first data with SwiftData
- Initial distribution is Xcode direct installation to the developer's own iPhone
- No App Store publication is required for the alpha
- No backend, authentication, cloud sync, subscriptions, or social features in the alpha

## 3. Product Boundary

### Included in v0.4 alpha

- Reference tone playback
- Realtime pitch detection
- Same-note imitation
- Delayed same-note recall
- Higher / lower / same listening discrimination
- Half-step and whole-step interval practice
- Minor/major third practice
- Perfect fourth and fifth practice where difficulty warrants
- Ascending and descending variants
- Reference-only interval generation: hear the root, internally generate the target, then sing
- Three-note melody imitation
- Three-to-five-note novel melody transfer
- Short sustain and drift measurement
- Five-minute diagnostic
- Skill profile
- Adaptive “Today’s 3 Minutes” prescription
- Local practice history
- Four training phases: Listen → Recall → Sing → Check

### Explicitly excluded

- Absolute-pitch training as a primary goal
- Full music theory curriculum
- Score-reading / conservatory sight-singing curriculum
- Copyrighted song ingestion or automatic commercial-song analysis
- Vocal-fold closure diagnosis
- Breath-support / abdominal-pressure diagnosis
- Laryngeal-position diagnosis
- Mix-voice / falsetto technique classification
- Screaming technique coaching
- Social / ranking systems
- AI chat as the primary interaction model

RETUNE may compare performance under different phonation conditions later, but it must not infer physiological causes from microphone audio alone.

## 4. Learning Model

RETUNE models pitch skill as independent but connected abilities rather than a single score.

### 4.1 Auditory discrimination

Can the user hear whether two tones differ and in which direction?

Key skills:
- higher / lower / same
- half-step vs whole-step
- ascending vs descending direction

### 4.2 Auditory retention

Can the user hold a heard tone or short pattern in memory after playback stops?

Key skills:
- delayed same-note recall
- delayed two-note recall
- short melody retention

### 4.3 Internal interval generation

Can the user hear one reference pitch, then internally generate the next pitch without hearing the target first?

Key skills are indexed by:
- interval size
- direction
- register
- prompt level

This is the core addition in v0.4.

### 4.4 Auditory-to-vocal mapping

Can the user sing the internally expected note directly, rather than search for it by sliding?

Key metric:
- Direct Landing Rate

### 4.5 Sequence transfer

Can isolated interval skills survive when embedded in three-to-five-note melodies, rhythm, pauses, and eventually simple accompaniment?

### 4.6 Pitch maintenance

Can the user remain centered after landing?

Key metrics:
- settling time
- median error
- stability
- drift

## 5. Core Training Loop

All active training follows the same state-driven interaction model.

```text
prepare
→ referencePlaying
→ recallSilence
→ recording
→ evaluating
→ result
→ next / retry
```

### Listen

Play one or more reference tones according to the exercise prompt level.

### Recall

Stop playback. Present a short silent interval, typically 1–4 seconds. The UI becomes visually quiet and prompts the user to hear the next pitch internally.

### Sing

Start voice capture. The user sings on a standard syllable such as “ねー”. Reference playback remains off during scored alpha exercises.

### Check

After the attempt, show:
- target relationship
- actual relationship
- signed cent error
- pitch trace
- direct-landing result
- one short observation
- retry or next action

The realtime UI may show listening state, but it should not reveal enough pitch correction information during the attempt to let the user visually steer into the correct note when the exercise is intended to test internal generation.

## 6. Prompt Levels

Difficulty is partly controlled by how much reference information the app provides.

### Level 0 — Full model

Hear every target note, then imitate.

### Level 1 — Model then delay

Hear the complete target, wait briefly, then reproduce.

### Level 2 — Reference note only

Hear only the root. The target interval is shown conceptually, then generated internally.

### Level 3 — Reference note + longer delay

Same as Level 2, with a longer silent retention period.

### Level 4 — Transposed start

Same interval relationship, new start pitch.

### Level 5 — Novel short melody

The trained interval appears inside an unfamiliar three-to-five-note pattern.

### Level 6 — Rhythm

Add BPM, note durations, and rests.

### Level 7 — Simple accompaniment

Place the skill into a minimal backing context.

A skill is not considered learned merely because the same exercise was repeated successfully. Transfer to a new root, novel item, or delayed review is required.

## 7. Diagnostic Design

The five-minute diagnostic identifies which layer breaks first.

### Section A — Listening discrimination

- 6–8 trials
- no singing
- higher / lower / same
- half-step / whole-step where appropriate

### Section B — Same-note reproduction

- 4–6 trials
- hear a note
- short silence
- reproduce on “ねー”

### Section C — Heard interval imitation

- 4–6 trials
- hear both tones
- reproduce relationship

### Section D — Reference-only interval generation

- 4–6 trials
- hear only the first tone
- target interval is indicated
- sing the second tone
- correct second tone is played only after the attempt

### Section E — Short melody transfer

- 3–4 unfamiliar three-note patterns
- full example → silence → sing

### Section F — Short sustain

- 2–3 trials
- land, then hold for roughly three seconds

The result does not diagnose physiology. It identifies the first observable skill boundary where performance deteriorates.

## 8. Skill Profile

User performance is stored by skill, not by exercise ID alone.

Examples:
- ascending_M2
- descending_M2
- ascending_M3
- descending_M3
- ascending_P4
- descending_P4
- ascending_P5
- descending_P5
- same_note_delayed_recall
- direct_single_note_landing
- three_note_melody
- five_note_melody
- repeated_note_then_move
- rest_then_landing
- short_sustain
- cumulative_sequence_drift

Each skill state also stores context such as register, prompt level mastered, recent bias, novelty success, and review timing.

## 9. Metrics

### Initial Error

Signed cent difference for the first reliable voiced region after onset filtering.

### Settling Time

Time from voiced onset until the user reaches the tolerance band and remains there long enough to count as settled.

### Median Error

Median signed cent error over the stable scored region.

### Stability

Percentage of eligible frames inside the configured tolerance.

### Drift

Pitch movement over a sustained segment, represented as cents per second.

### Direct Landing Rate

Percentage of attempts whose first reliable landing is already inside the acceptance band without a corrective search.

### Interval Error

Difference between the intended interval and the interval actually produced.

Example:

```text
reference: C4
intended target: E4
expected interval: +400 cents
actual sung interval: +458 cents
interval error: +58 cents
```

### Interval Bias

Repeated signed tendency for a specific interval and direction.

Example:

```text
ascending major third: average +42 cents
```

### Delayed Recall Error

Pitch error after the reference has stopped for a defined silent interval.

### Cumulative Sequence Drift

Net tendency for a multi-note scale or sequence to progressively shift its internal tonal center upward or downward.

## 10. Adaptive Prescription

The app should answer one question after every diagnostic or practice session:

> What is the smallest underlying pitch skill that should be trained next?

Priority is calculated from a combination of:
- mastery deficit
- recent error magnitude
- direct-landing rate
- due-for-review state
- novel-item performance
- melody-transfer performance

Rules:

- If listening discrimination fails, do not prescribe vocal interval generation yet.
- If listening succeeds but full-model imitation fails, prescribe auditory-to-vocal mapping.
- If full-model imitation succeeds but reference-only generation fails, prescribe internal interval generation.
- If isolated intervals succeed but short melodies fail, prescribe sequence transfer.
- If landing succeeds but sustain fails, prescribe maintenance/stability.
- If fundamentals succeed but accompanied tasks fail, prescribe transfer under rhythm/attention load.

## 11. Today’s 3 Minutes

The existing “Calibration → Correction → Transfer” structure remains, but its meaning changes.

### Calibration — 30–45 sec

- same-note reference
- delayed same-note recall
- quick preview of today’s target relationship

### Correction — 90–120 sec

Practice exactly one main weakness.

Example: ascending major third

```text
full model
C → E
↓
reference only
C → [silence] → user sings E
↓
transpose
D → [silence] → user sings F#
↓
novel root
```

On failure, reduce prompt difficulty or interval complexity. On success, remove guidance or change the root.

### Transfer — 45–60 sec

Embed the trained relationship into an unfamiliar three-to-five-note phrase, then optionally add BPM or simple accompaniment.

## 12. UI Architecture

The existing visual direction remains authoritative:
- dark-first
- near-black background
- mint/cyan luminous accent
- restrained glass surfaces
- glow used for active state, not decoration everywhere
- strong spacing hierarchy
- one primary action per screen
- bottom navigation hidden during active training

The product retains four top-level destinations:
- Home
- Practice
- History
- Settings

### Home

- Today’s 3 Minutes
- Five-minute diagnostic
- current strongest/weakest skill summary
- recent change
- 14-day progress

### Practice

Entry into guided adaptive exercises rather than an unrestricted tuner-first utility.

### Active exercise screen

Information hierarchy:
1. what relationship to produce
2. current phase: Listen / Recall / Sing / Check
3. immediate result after the attempt
4. retry / next

During Recall, visual feedback is intentionally minimal to support internal hearing.

### Result screen

First layer:
- one short observation
- one main metric
- retry / next

Expanded layer:
- pitch trace
- signed cent values
- interval error
- direct landing
- stability / drift where relevant

## 15. Pitch Detection Contract

The detector must be swappable.

```swift
protocol PitchDetector {
    func detect(samples: [Float], sampleRate: Double) -> PitchDetectionResult?
}
```

`PitchDetectionResult` contains at minimum:
- frequencyHz
- confidence

The analysis pipeline adds:
- note mapping
- cent error
- voiced state
- continuity handling
- octave-jump filtering
- smoothing

The first detector may use autocorrelation or YIN-family logic. The architecture must allow later replacement with a better detector without changing training logic or screens.

## 16. Audio Flow

### Reference phase

- configure AVAudioSession
- play generated reference tone at A4=440 equal temperament
- stop playback before scored recording

### Recording phase

- microphone input tap receives buffers
- low-RMS frames are ignored
- detector produces frequency + confidence
- low-confidence frames are ignored rather than scored as wrong
- recent pitch continuity is used to reject likely octave errors
- accepted pitch frames are buffered for attempt analysis

### Post-attempt analysis

Calculate metrics from buffered frames only after onset exclusion and confidence filtering.

## 18. Error Handling

- Microphone permission denied: keep reference playback available and show exact action needed to enable microphone access.
- No confident pitch: show listening state rather than a false note.
- Audio session interruption: pause exercise and require explicit resume.
- App backgrounding: terminate or pause the active attempt safely.
- Very noisy input: reject low-confidence frames and explain that the attempt could not be scored reliably.
- Out-of-range singing: preserve raw attempt record where possible, but do not award a false success.

## 19. Testing Strategy

### Unit tests

- note / MIDI / frequency conversion
- cent conversion
- interval calculation
- generated melody constraints
- direct landing calculation
- interval error / bias
- drift
- prompt-level transitions
- prescription rules
- review scheduling

### Synthetic audio tests

Generate known sine waves and controlled pitch offsets for:
- A3 220 Hz
- C4 approximately 261.63 Hz
- E4 approximately 329.63 Hz
- A4 440 Hz
- offsets such as ±10, ±20, ±50, ±100 cents

Validate sign, magnitude, smoothing, and octave-guard behavior.

### Device tests

Primary device: user’s iPhone.

Validate:
- microphone permission
- reference-tone playback
- recording latency
- ordinary sung vowels
- breathy onset
- short note transitions
- sustained note drift
- speaker leakage behavior
- interruption / backgrounding
- common iPhone layouts

The first implementation should not attempt the entire product at once.

### Slice 1 — Measurement proof

- SwiftUI shell
- AVAudioSession
- reference tone
- microphone capture
- pitch detector interface
- current frequency / cents debug view

### Slice 2 — Single-note proof

- same-note imitation

### Slice 3 — Interval proof

- reference-only M2 and M3 generation

- interval bias history

This slice is the key v0.4 proof: RETUNE must be able to distinguish “can imitate the target when heard” from “cannot internally generate the target from the root alone.”

### Slice 4 — Diagnostic and adaptive prescription

- five-minute diagnostic
- skill profile
- prescription engine
- Today’s 3 Minutes

### Slice 5 — Melody transfer

- novel three-note patterns
- five-note patterns
- BPM / rests
- simple accompaniment

### Slice 6 — History and 14-day comparison

- progress summaries
- delayed review
- repeat baseline diagnostic
- novel-item comparison

## 21. Definition of Done for v0.4 Alpha

The alpha is successful when the user can install the app directly from Xcode onto an iPhone and:

1. hear a reference note,
2. reproduce the same note,
3. reproduce it after a short delay,
4. hear only a reference note and attempt a requested interval without hearing the target first,
5. receive a correct signed interval-error result,
6. practice the same interval from a different root,
7. complete a five-minute diagnostic,
8. receive an automatically chosen three-minute exercise based on observed weakness,
9. transfer the trained interval into an unfamiliar short melody,
10. review local progress over time.

The result language must describe observed pitch behavior, not speculate about vocal physiology.
